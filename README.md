# <p align="center"> CarbonCompass </p>

### <p align="center"> Providing guidance and direction in reducing emissions </p>
<br>



## Installation Instructions

Please begin by forking the repo to your GitHub account if you plan to make changes.


Clone the repo locally and make sure you install all dependencies:

```
npm install
```
To run the app in a development environment, use:
```
npm run dev:all
```

If you want to test the app's functions, you can run:
```
npm run test
```

### API Keys:
You can make your own API keys to run this application by creating an account with <a href="https://www.carboninterface.com/">Carbon Interface </a> and <a href="https://openai.com/index/openai-api/">OpenAI</a>

> **NOTE:** Currently, our Carbon Interface API key is hard coded in the vehicle and electricity controller files. The OpenAI key is referenced through a .env file which you will need to create on your own (because that one is expensive).
